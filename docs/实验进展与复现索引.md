## 评估范围

**课程主实验。** `configs/experiment.json` 使用种子 20261121，从 699,960 条有标签数据中分层保留 139,992 条独立测试样本，其余 559,968 条固定三折。首轮在开发集上冻结模型、权重和 F1 阈值后完成独立测试。第二轮神经网络及整数与小数档系列沿用开发集三折。

**后续五折脚本。** `experiments/s6e11/prepare_split.py` 先按 ID 排序，以 PCG64 种子 42 在各标签内划分，约 20% 标为 `fold=-1`，其余分成五折。该划分与课程主实验不同。重新划分不会使已查看的标签恢复为未见标签，五折结果单独记录。

**公开预测。** Alex Chilton 的 OOF 来自作者的训练划分，本项目将其对齐到开发集选择融合权重。最新 45∶45∶10 方案使用三份公开比赛测试预测，本仓库没有相应的权重选型 OOF，其证据为实测公榜成绩和归档 CSV。

## 实验分别回答了什么

参数搜索、手工特征与交叉拟合目标编码检验输入和模型组合的效果。整数档、小数档与浅树对照进一步检验重复取值的风险信息，以及树容量对这套表示的影响。GLM 起点实验把逻辑回归的 logit 传给提升树，比较可加基准与残差修正的组合。

第二轮 MLP、FT-Transformer、TabM 使用相同三折。TabM 在单个网络中 AUC 最高，且与树模型互补，所选权重为树融合 0.9、TabM 0.1。NumPy 逻辑回归与 sklearn 对照检验目标函数和求解结果；鲁棒性实验在配对样本上比较训练量、噪声和异常值的影响。

后续加性样条网络将六列数值的原始表示、离散键风险编码和其他字段展开为分段线性基函数。风险率在训练折内估计，训练行采用内部五折编码，标准化统计量也来自训练行。代码用拼接后的训练与比赛特征枚举离散键，标签统计仍限于训练行。网络固定训练 12 轮，比较可加结构与八维低秩交互。

`train_bpe_tree.py` 使用 GPT-2 数字分词合并表构造数值 token 键，再训练 LightGBM；它与 GPT 小样本分类属于不同实验。GPT 分类对照使用 256 笔既有留出交易，结果和区间见 `reports/llm_pilot_v1/`。

## 复现入口与材料

| 内容 | 入口 | 所需材料 |
|---|---|---|
| 课程主实验、手写算法及鲁棒性 | `scripts/run.py all` | 官方三个 CSV、主环境、可用 GPU |
| 第二轮神经网络 | `scripts/run_neural.py` 分阶段命令 | 神经网络环境及首轮持久化结果 |
| 报告正文 | `scripts/run.py report` | 已归档指标、本机 `artifacts/` 绘图预测 |
| Word 报告 | `scripts/build_docx.py` | `report_content.json`、图表、教师模板和文档依赖 |
| 后续加性网络 | `prepare_split.py`、`train_context_network.py` | 独立目录中的官方 CSV、CUDA PyTorch，详见该目录 README |
| 最新公开预测融合 | 固定版本预测的百分位秩加权 | 三份指定版本 `submission.csv`；最终 CSV 已归档 |

`scripts/run.py all` 覆盖课程主实验和选做实验。神经网络及后续五折脚本按各自入口运行。`experiments/s6e11/` 没有归档该轮 `runs/`、`references/` 或完整锁定环境，因此脚本说明与可直接核验的结果分别列出。

课程首轮与第二轮核验见 `reports/verification.json`、`reports/round2/verification.json`，范围不包含全部后续探索。最新公开融合的 ID 顺序、分数格式、SHA256 和真实提交状态见 `reports/competition_progress.json`；格式检查不替代缺少输入时的融合重算。
