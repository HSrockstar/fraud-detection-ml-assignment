# 分类作业要求与完成证据

正式依据为 `作业要求/机器学习-作业2-分类算法（作业要求）-2026 (1).pdf`。随附模板中的回归示例按分类目标改写，原始要求与模板均保留。

| 要求 | 对应实现与交付证据 |
|---|---|
| 自选分类任务、说明来源、输入及类别分布 | Kaggle 信用卡欺诈二分类；`reports/eda_summary.json`、`reports/feature_profile.csv`、报告课题综述 |
| 数据处理、合理划分与避免数据泄漏 | `src/fraud/common.py`、`features.py`、`models.py`；固定 20% 独立测试与开发集三折；训练折内拟合预处理、内部早停 |
| 至少两类传统分类方法及原理、参数 | 逻辑回归、决策树、XGBoost、CatBoost；报告模型搭建与参数表 |
| 相同条件公平比较 | 共用划分、种子、指标；`reports/experiments/`、`reports/model_comparison.csv` |
| 至少两种分类指标 | ROC-AUC、AP、Accuracy、Precision、Recall、F1、LogLoss；`reports/holdout_metrics.json` |
| 真实值与预测值对比、不同模型对比 | `reports/figures/confusion_matrix.png`、`model_comparison.png`、`pr_curves.png`、`roc_curves.png` |
| 至少优化一种模型并解释前后差异 | Optuna 搜索、同参数特征工程消融与交叉拟合目标编码；`reports/optimization_trials.csv`、`optimization.json`、报告优化分析 |
| 测试集仅用于最终评估 | `reports/selection.json` 在生成 holdout 预测前冻结；`reports/holdout_metrics.json`，最终选型不按测试结果修改 |
| 报告结构与实验总结 | `reports/实验报告.md`、`reports/信用卡欺诈预测_分类实验报告.docx` |
| 15 页以内 | 以 Word 最新渲染页数核验，证据记录在 `reports/document_verification.json` |
| 小组姓名学号和具体分工 | `configs/team.json` 记录四名成员；按用户明确要求，分工栏暂时留白，提交前补齐 |
| 可运行代码、运行环境、依赖与数据获取 | `README.md`、`scripts/setup.ps1`、`requirements-lock.txt`、`scripts/download_data.py`、`reports/environment.json` |
| 引用来源、禁止伪造 | 报告参考资料、官方数据 SHA256 清单、逐折参数和预测文件；线上分数仅在实际提交后记录 |
| 拓展选做 | 特征工程、超参数分析、模型融合与可解释性；第二轮增加 GPU MLP、FT-Transformer、TabM 的实际训练、曲线与融合对照，记录于 `reports/round2/` |

最终实验与提交文件的自动核验见 `reports/verification.json`。分工留白是用户明确指定的待补项，不能称为已经满足教师对具体分工的最终提交要求。
