更新日期：2026-11-24。已完成实验与入口见 [实验进展与复现索引](实验进展与复现索引.md)，逐次指标保留在各自的 JSON 中。

## 当前基准

课程主实验以统一三折比较和首轮冻结评估为依据：首轮独立测试 AUC 为 0.952060；加入 TabM 后，第二轮开发集 OOF AUC 为 0.946356。

比赛侧分别保留团队自训与公开融合的参照：整数与小数档 7∶3 融合实测公榜 AUC 为 0.95132，三份公开预测 45∶45∶10 融合为 0.95567。公开融合与其中两份原版在公榜五位小数精度上持平，不据此声称融合显著改善。

## 下一轮优先事项

1. 补全种子 42 五折实验的结果归档。现有目录保留训练脚本，没有该轮 `runs/`、逐折 OOF 和模型权重。恢复或重跑时先保存 ID、折号、配置、环境与逐折预测，再对候选作配对比较。
2. 固定一种输入表示，比较可加结构和低秩交互。`train_context_network.py` 已提供两种结构，应共用划分和训练预算，分别记录单模型 AUC、折间变化及融合收益。
3. 先检验互补性，再增加融合成员。最新三方公开融合没有归档权重选型 OOF，不能补写为经过本地交叉验证选出的权重。

`reports/ranking_ceiling.md` 针对既定 7∶3 模型描述排序误差。单列区分度与分组误差可帮助提出假设，但不构成现有字段的性能上限，也不足以排除新的编码与交互方法。

后续模型选型继续使用开发集。首轮测试集已经参与最终评估，重新划分不会使已查看的标签恢复为未见标签。公榜只记录真实提交成绩，排名须附实际核对时间。
