# 比赛优化到此的判断

判断依据是开发集上的折外预测，见 `reports/ranking_ceiling.md`。当前提交仍是整数档和小数档上的 XGBoost 70% 加 CatBoost 30%。这次没有训练新模型，也没有使用已经看过的 20% 独立测试集。

结论是停止在现有列上继续加特征或更换模型。

全体 AUC 0.9478 里，超过一半的欺诈—正常配对是“有响亮标记的欺诈”对上“没有任何这些标记的正常交易”，这部分已经有 99.4% 排对。有标记交易内部的胜率是 92.4%。标记完全相同的格子里，当前融合仍有 0.8435 的 AUC，这是商户风险、交易速度和 CVV 次数已经贡献的排序，不是还没做的步骤。

没有这些标记的欺诈有 540 笔，概率中位数 0.0049，无标记正常交易的 90 分位是 0.0046。现有列把它们定义成低风险，再换一个看同样列的模型，给不出另一套排序。

原先列出的方向按这次检查收束如下：

1. 交互目标编码和更多数值档位：整数档加小数档已经比交互档更好。夜间、距离、余额、金额、星期、卡组织和渠道，在有标记交易上的单列 AUC 为 0.50 到 0.54。
2. 再调树的深度或正则：标记内部还靠连续的风险分和速度排序，当前深度 3 的树已经接收这些列。
3. 多种子或另一套切分的浅模型：它看到的仍是同一批标记，补不上 540 笔无标记欺诈，也分不开高分正常交易和高分欺诈。
4. 神经网络：第二轮 MLP、FT-Transformer、TabM 的开发集 OOF 都低于当时的树融合。
5. 年龄：有标记交易里 18 岁欺诈率 0.53%，81 岁 5.18%，模型已经把年龄当作数值列。它是随年龄抬高的，不是风险整数档那种跳变。

课程报告 `reports/实验报告.md` 由脚本按首轮和第二轮神经网络的结果生成。这篇判断单独存放，避免重做课程报告时被覆盖。

## 2026-11-21 浅树复核

上面的判断针对夜间、距离、余额这类新列，以及再换一个看同样表示的模型。它没有覆盖“把现有整数档和小数档交给更浅的树”。

在同一套整数档、四位小数档、平滑 80 和深度 3 的学习率上，只改容量：

| 模型 | 开发集 OOF AUC | 相对深度 3 |
| --- | ---: | ---: |
| 按损失生长，最多 3 叶 | 0.948146 | +0.000834 |
| 深度 1，以及按损失生长的 2 叶 | 0.948133 | +0.000820 |
| 深度 2 | 0.947867 | +0.000555 |
| 按损失生长，最多 4 叶 | 0.947696 | +0.000384 |
| 原深度 3 | 0.947312 | 0 |

2 叶和深度 1 的三折结果完全相同。3 叶只比深度 1 高 0.000013。更深的树在这套编码上更差。记录在 `reports/leaf_capacity.json`。

在 3 叶模型上再加两位小数尾数和十位分组，OOF AUC 0.948140，相对 3 叶变化 -0.000006，不采用。记录在 `reports/tail_keys.json`。

3 叶和深度 1 按 1:1 融合的开发集 OOF AUC 为 0.948309。该文件已提交，公开分 0.95041，低于仍在榜上的 7:3 融合 0.95132。队伍最好成绩不变，2026-11-21 核对时排名 904/2571。浅树的开发集提升没有转移到公开榜。

深度 3 的 GLM 已在开发集跑完，见 `reports/glm_boost.json`。逻辑回归 `C=0.01` 的 logit 作为 `base_margin`。单模型 OOF AUC 0.948240，比深度 3 高 0.000927，三折都上升；比 7:3 融合高 0.000423。再与 CatBoost 按 0.8/0.2 融合为 0.948370。单模型已提交，见 `reports/glm_submission.json`。全量重训 155 轮，公开分 0.95120（ref 58702370），没有成为队伍最好成绩。若以这个分数计，大约排在 963/2628。公开榜有效提交仍是 7:3 融合 0.95132，2026-11-22 核对时官方排名 920/2628。

同一棵公开榜有效的深度 3，同时接收平滑 5、20、80 三套目标编码，见 `reports/multi_smooth.json`。开发集 OOF AUC 0.947231，比只用平滑 80 的深度 3 低 0.000081，比 7:3 融合低 0.000585。三折里只有第一折上升。与 7:3 的 Spearman 相关 0.9897。没有上传。

CatBoost 使用同一套整数档和小数档，并把平滑 80 的逻辑回归 logit 当作起点，见 `reports/cat_glm.json`。单模型 OOF AUC 0.947541，比原来的 CatBoost 高 0.001969，三折都上升，轮数 819 / 873 / 727。与深度 3 按 1:1 融合为 0.948340，比当前 7:3 高 0.000524，三折分别高 0.000491、0.000524、0.000549。与 7:3 的 Spearman 相关是 0.9952。

该 1:1 文件已提交，见 `reports/cat_glm_submission.json`。公开分 0.95120（ref 58702109），低于当时的 7:3 融合 0.95132。

2026-11-22 用 Alex Chilton 以 CC0 公开的折外预测，在我们的开发集上做名次平均，见 `reports/public_oof_blend.json`。选中的权重是我们的 7:3 占 0.1，两份 LightGBM 占 0.4 和 0.5。开发集 AUC 0.950031，比 7:3 高 0.002214。公开分 0.95146（ref 58703492），成为新的队伍最好成绩。核对时官方排名 874/2634。
