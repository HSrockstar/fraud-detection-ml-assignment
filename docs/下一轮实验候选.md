# 下一轮比赛优化候选

本轮冻结方案为目标编码 XGBoost 70% 与 CatBoost 30%。开发集 OOF AUC 为 0.946274，独立测试 AUC 为 0.952060；后者只代表本次本地划分，不是 Kaggle 线上分数。

优先尝试以下方向，每次只改变一个因素，并保存 OOF 预测用于同划分比较：

1. **交互目标编码**：从 CVV 重试、验证方式、境外交易、商户风险等特征中选择少量组合，保留内部交叉拟合；比较平滑强度和类别频次限制。
2. **目标编码参数与模型容量**：本轮目标编码沿用原始特征搜索得到的参数，可单独优化其深度、正则化和轮数；不默认增加树深度能改善表现。
3. **公开原始数据源辅助特征**：先核对比赛规则及官方数据说明，再检查公开源与本比赛的列、取值、标签和重复关系。比较额外训练样本与源数据统计特征，记录数据来源。
4. **稳定性与互补性**：对较好的少量候选增加五折或多种种子实验，比较单模型收益、折间变化和融合收益。单 GPU 顺序训练。
5. **异构模型**：在树模型收益趋于稳定后，测试小型 GPU MLP 是否提供不同的错误分布；用验证增益与耗时决定是否加入融合。

本轮金额比例、时间周期和风险乘积等组合特征的 OOF AUC 没有超过同参数原始特征模型，可优先保留目标编码路线。原始四类基线与本轮所有实验保留，不覆盖结果。

本轮模型选择和阈值已冻结，独立测试也已完成。下一轮应单独记录实验名称、配置和选择过程，在开发集内选型；既有测试集的成绩不能用作反复调参依据。首次 Kaggle 提交后，再核对提交记录和真实线上成绩。
